PROJECT DAEDALUS

Launch
1. On a Windows 10/11 PC with a 64-bit processor, double-click PROJECT DAEDALUS.exe.
2. No Godot installation is required.

Controls
- Move: W A S D or arrow keys
- Look: mouse
- Interact / continue dialogue: E
- Sprint: Shift
- Change camera shoulder: Q
- Pause or cancel: Esc

The complete editable Godot project is in the Source Code folder. Open its project.godot file in Godot 4.3 to inspect or edit the project.
